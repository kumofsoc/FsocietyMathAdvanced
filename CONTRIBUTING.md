# Contributing to MathMaMath

MathMaMath содержит frontend приложения MathMaMath. Предложения и Pull Requests приветствуются при соблюдении требований к качеству и безопасности.

## Разработка

Требуются Node.js 22 и pnpm, совместимый с `packageManager` в `package.json`.

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

Перед PR:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
```

Изменения, затрагивающие API или авторизацию, проверяются с существующим контрактом в `docs/backend-contract.md`. Не создавайте несуществующие backend endpoints. При наличии доступного тестового backend используйте `pnpm test:e2e:backend`.

## Порядок изменений

1. Для дефектов и предложений используйте Issue. Для уязвимостей только [приватный канал](SECURITY.md).
2. Создавайте отдельную ветку для одного логического изменения; `main` не используется для экспериментальных коммитов.
3. Добавляйте тесты для исправленного поведения и особенно для авторизации, токенов, хранения данных и маршрутов.
4. Не включайте реальные токены, пароли, персональные данные, файлы `.env` и дампы баз.
5. Создайте Pull Request с описанием задачи, рисков, проверок и возможного влияния на данные.
6. Не меняйте публичные API и формат хранилища без миграционного плана. Учитывайте доступность, локальный режим и поддержку мобильных устройств.

## Проверки

CI, CodeQL и Dependency Review выполняются на Pull Requests. Успешный результат не заменяет анализа логики доступа к данным и безопасного поведения приложения. Не используйте `pull_request_target` для выполнения недоверенного кода.

Изменения выполняются по техническим критериям: корректность, тестируемость, безопасность, совместимость и соответствие назначению проекта.

Правила общения: [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
