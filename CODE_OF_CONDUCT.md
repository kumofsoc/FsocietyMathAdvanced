# Code of Conduct

В обсуждениях MathMaMath придерживаются технической аргументации, уважительного взаимодействия и прозрачного разбора ошибок.

Допустимы критика кода, архитектуры, решений и аргументов. Недопустимы угрозы, травля, дискриминационные высказывания, разглашение персональных данных и публикация секретов или уязвимостей вне приватного канала.

Issues и Pull Requests должны оставаться по теме проекта. Спам, вредоносные изменения и попытки обойти проверки могут быть закрыты или ограничены.

Сообщения о нарушениях правил сообщества направляются через доступные средства приватной связи GitHub; уязвимости направляются исключительно по [SECURITY.md](SECURITY.md).

Решения о модерации основываются на характере поведения и безопасности проекта, а не на личных характеристиках участников.
