# VisualMath Profile + Map / 30th-Century Design

## Goal

Bring Account and Course Map to the same visual quality and design language as the rebuilt home page without duplicating the home page scene system.

## Profile direction: PERSONAL OS / IDENTITY CORE

- Identity core instead of a conventional profile card.
- Large personal monogram/avatar surrounded by progress rings and technical marks.
- Real course progress, solved/theory/saved counts remain the primary data.
- Editing becomes an embedded identity console rather than a plain form.
- Activity heatmap becomes an activity matrix.
- Visits become a signal waveform.
- Chapter progress becomes a sector matrix.
- Decorative text is clearly aesthetic and does not masquerade as real analytics.
- Strong asymmetry, huge numerals, grid/noise overlays, clipped technical surfaces.
- Mobile falls back to stacked readable modules.

## Map direction: NAVIGATION CORE / KNOWLEDGE SPACE

- G6 remains the graph engine and source of graph geometry.
- Header becomes a navigation-core HUD with giant map identity and live course mastery.
- Chapter tabs become a sector rail.
- Summary becomes map telemetry.
- Canvas becomes a framed spatial viewport with coordinate marks and scanline/noise layers.
- Inspector becomes a deep glass/metal analysis console.
- Existing click/double-click/selection/fullscreen behavior remains unchanged.
- Node visuals get a stronger futuristic treatment through G6 styles only; no React overlay coordinates.
- Real prerequisites remain solid; study flow remains dashed.
- No extra graph renderer is introduced.

## Shared design language

- Technical thin borders.
- Controlled accent glow.
- Large editorial type.
- Monospace telemetry labels.
- Perspective grids and scanline/noise texture.
- Clipped corners and asymmetrical layouts.
- Theme variables remain authoritative.
- Motion respects existing profile settings and reduced motion.
- Functional labels stay readable; tiny text is decorative only.

## Performance and resilience

- No new third-party dependencies.
- No new WebGL canvas for profile/map.
- G6 layout logic is not changed unless required for style compatibility.
- CSS animations are low-cost and disabled under motion=off / reduced motion.
- Existing build/test contracts remain green.


## Added scope: Academy, Review and System Config

The same redesign pass also covers the two special sidebar modes and personalization overlay.

### LINEAR LAB
Linear Academy is treated as a professional mathematical laboratory: dense metrics, protocol flow, chapter modules and proof/capstone tags.

### REVIEW ARCHIVE
The concise review mode is treated as a future reference archive: sticky filter bus, document-like topic sheets and formula-focused surfaces.

### SYSTEM CONFIG
Settings becomes the VisualMath operating-system configuration console. Existing theme, cursor, motion, music and saved-theorem behavior remains unchanged.

### Sidebar entrances
Linear Academy and Review receive distinct visual identities directly in the sidebar while preserving the existing navigation behavior.
