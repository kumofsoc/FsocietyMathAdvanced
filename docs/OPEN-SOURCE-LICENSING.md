# Open-source licensing: decision required

Публичная видимость GitHub-репозитория **сама по себе не предоставляет лицензию** на копирование, переработку и распространение исходного кода. Для публикации полноценного open-source проекта необходим отдельный `LICENSE` с условиями использования.

Варианты:

- **AGPL-3.0-only**: исходный код модификаций сетевого сервиса должен предоставляться в установленных лицензией случаях; полезно при желании сохранить публичность производных серверных версий.
- **GPL-3.0-only**: copyleft при распространении модифицированных версий; сетевое использование без распространения в общем случае не запускает тот же механизм, что AGPL.
- **Apache-2.0**: разрешительное лицензирование с явным положением о патентных правах.
- **MIT**: простая разрешительная лицензия, допускающая закрытые производные версии.

Ни одна лицензия не предотвращает злонамеренное поведение в форках, DDoS или взлом инфраструктуры. Лицензирование и защита GitHub `main` решают разные задачи.

Файл `LICENSE` намеренно не добавлен до явного выбора условий. Перед выбором необходимо проверить права на весь включённый код, контент, иллюстрации, шрифты и сторонние материалы; лицензия frontend не распространяется автоматически на отдельный backend.
